\section*{\textbf{Heterogeneous Federated Prompt Optimization for Medical QA:} How Novel Is It?}


HFPO sits at the intersection of federated prompt learning, evolutionary prompt search, and medical LLM evaluation. Existing work gets close to each piece separately, but does not appear to combine them in exactly the way you propose.


\subsection*{Closest Existing Directions}


\subsubsection*{\textbf{Federated Prompt Learning / Tuning}}


\begin{itemize}
\item \textbf{FedBPT, Fed-BBPT, FedPrompt, PromptFL, FedDTPT, DP-FPL, Probabilistic FL prompt tuning, SecFPP, FedPSF-LLM} all let clients collaboratively train prompts (often \textit{soft} prompts) with frozen PLMs/LLMs, focusing on communication efficiency, privacy, personalization, differential privacy, and robustness to \textbf{non-IID} data  \cite{Sun2023FedBPT:} \cite{Li2024Federated} \cite{Zhao2022FedPrompt:} \cite{Lin2023Efficient} \cite{Wu2024FedDTPT:} \cite{Tran2025Privacy-Preserving} \cite{Guo2023EvoPrompt:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item Several explicitly handle heterogeneous / non-IID data and imbalanced settings, often with specialized aggregation or personalization  \cite{Wu2024FedDTPT:} \cite{Guo2023EvoPrompt:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\end{itemize}


These are strong prior art for “federated prompt learning,” but they generally optimize prompt \textit{parameters} with gradient(-free) methods, not an explicit \textbf{population of discrete system prompts} evaluated only via black-box scores across sites.


\subsubsection*{\textbf{Evolutionary + LLM-Based Prompt Optimization}}


\begin{itemize}
\item \textbf{EvoPrompt} uses an EA-style population of discrete prompts; a GA loop with selection plus LLM-based crossover/mutation, evaluated on a dev set, without using gradients  \cite{Weng2025Probabilistic} \cite{Guo2022PromptFL:}.
\item \textbf{GAAPO} similarly applies genetic algorithms for prompt optimization, integrating multiple prompt generation strategies within an evolutionary framework  \cite{S'echeresse2025GAAPO:}.
\end{itemize}


These give direct precedent for \textbf{GA + LLM-based prompt generation}, but in a centralized, single-dataset setting.


\subsubsection*{\textbf{Federated, Non-IID Medical NLP}}


\begin{itemize}
\item Multiple works show federated fine-tuning or FL approaches on heterogeneous clinical text (e.g., layer-skipping FL for healthcare NLP; FL evaluation on biomedical IE)  \cite{Jiang2025Fine-tuning} \cite{Wang2025Multi-Modal}, and surveys highlight FL as a key privacy tool for biomedical LLMs  \cite{Peng2024An}.
\item Med-PaLM 2 and FedMME show high-stakes medical QA and multimodal medical federation but not federated prompt optimization itself  \cite{Guo2023Connecting} \cite{Li2026Evolutionary-Algorithm-Based}.
\end{itemize}


\subsection*{What Seems Novel vs. Covered}


\subsubsection*{\textbf{Already Explored Elements}}


\begin{itemize}
\item \textbf{Federated prompt learning/tuning} (soft or discrete) with non-IID data and privacy constraints  \cite{Sun2023FedBPT:} \cite{Zhao2022FedPrompt:} \cite{Lin2023Efficient} \cite{Wu2024FedDTPT:} \cite{Guo2023EvoPrompt:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item \textbf{Prompt personalization} in federated settings (global + client-specific prompts)  \cite{Tran2025Privacy-Preserving} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item \textbf{Evolutionary / GA + LLM-based prompt generation} for centralized prompt optimization  \cite{Weng2025Probabilistic} \cite{S'echeresse2025GAAPO:} \cite{Guo2022PromptFL:}.
\item \textbf{Black-box, gradient-free prompt optimization in federated LLM settings} (e.g., FedBPT/Fed-BBPT, FedDTPT)  \cite{Sun2023FedBPT:} \cite{Li2024Federated} \cite{Lin2023Efficient} \cite{Wu2024FedDTPT:}.
\end{itemize}


\subsubsection*{\textbf{Aspects That Appear Novel}}


Based on the abstracts, there does \textbf{not} appear to be:


\begin{itemize}
\item A framework that:\begin{itemize}
\item Maintains a \textbf{global population of discrete system prompts} on a server,
\item \textbf{Broadcasts the same population} to multiple clients,
\item Lets each client \textbf{only return evaluation scores per prompt},
\item Aggregates these into a \textbf{per-prompt, per-client fitness vector}, and
\item Uses a \textbf{GA where LLM(s) implement mutation/crossover} conditioned on those multi-hospital fitness signals,
\item To jointly produce \textbf{globally robust and site-specific prompts} for medical QA.
\end{itemize}


\end{itemize}


This specific combination — \textbf{EvoPrompt/GAAPO-style LLM-driven evolutionary search} + \textbf{purely score-based federated evaluation across heterogeneous clinical sites} — does not show up in the retrieved work.


\subsection*{Non-IID Federated Prompt Optimization}


\begin{itemize}
\item Several methods explicitly target non-IID or imbalanced settings in federated prompt learning, including \textbf{FedDTPT} (robustness to non-IID), \textbf{probabilistic federated prompt-tuning} for extreme heterogeneity, and personalized FPP methods like \textbf{SecFPP}  \cite{Wu2024FedDTPT:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item These typically aggregate prompt parameters or probabilistic representations, not \textit{evaluation-only} fitness in a black-box evolutionary loop.
\end{itemize}


\subsection*{Likely Contribution \& Reviewer Expectations}


\subsubsection*{\textbf{Methodological Contribution}}


If implemented and evaluated rigorously, HFPO would likely be viewed as a \textbf{non-trivial methodological contribution}, because:


\begin{itemize}
\item It introduces a \textbf{new optimization paradigm}: federated, black-box, population-based prompt search where \textbf{no model parameters or prompts are shared as gradients/weights}, only scores.
\item It connects \textbf{EvoPrompt-style prompt evolution} with \textbf{federated evaluation over non-IID medical data}, which current works only cover separately  \cite{Wu2024FedDTPT:} \cite{Weng2025Probabilistic} \cite{S'echeresse2025GAAPO:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\end{itemize}


Strength would depend on showing:


\begin{itemize}
\item Clear \textbf{privacy and communication advantages} over federated prompt tuning / federated fine-tuning baselines  \cite{Sun2023FedBPT:} \cite{Li2024Federated} \cite{Zhao2022FedPrompt:} \cite{Lin2023Efficient} \cite{Jiang2025Fine-tuning} \cite{Guo2023EvoPrompt:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item Gains in \textbf{cross-hospital robustness} and/or \textbf{personalization} on realistic medical QA benchmarks  \cite{Guo2023Connecting} \cite{Peng2024An} \cite{Wang2025Multi-Modal} \cite{Li2026Evolutionary-Algorithm-Based}.
\end{itemize}

\subsection*{Gaps HFPO Could Address}


\begin{itemize}
\item \textbf{No current work} combining: GA + LLM-based \textbf{discrete prompt evolution}, \textbf{federated, score-only evaluation} across heterogeneous institutions, and \textbf{explicit multi-objective selection} for global vs. site-specific prompts  \cite{Sun2023FedBPT:} \cite{Lin2023Efficient} \cite{Wu2024FedDTPT:} \cite{Weng2025Probabilistic} \cite{S'echeresse2025GAAPO:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\item Limited exploration of \textbf{federated prompt optimization specifically for medical QA}, where question distributions and clinical styles vary strongly across hospitals  \cite{Guo2023Connecting} \cite{Peng2024An} \cite{Wang2025Multi-Modal} \cite{Li2026Evolutionary-Algorithm-Based}.
\item Underexplored trade-offs between \textbf{privacy (score-only sharing)}, \textbf{communication cost}, and \textbf{robustness to extreme non-IID} in prompt-only frameworks  \cite{Sun2023FedBPT:} \cite{Li2024Federated} \cite{Lin2023Efficient} \cite{Wu2024FedDTPT:} \cite{Singhal2025Toward} \cite{Abdolmaleki2025Sync-GWO:}.
\end{itemize}


\subsection*{Conclusion}


Existing research already covers federated prompt learning (including non-IID and personalization) and evolutionary / GA + LLM-based prompt optimization, but in \textbf{separate} lines of work. There is no clear evidence of a method that unifies them into a score-only, GA-driven, federated prompt evolution framework for medical QA. HFPO therefore appears to target a real gap, and with strong experiments against modern federated prompt and fine-tuning baselines, it would likely be viewed as a meaningful methodological advance.
